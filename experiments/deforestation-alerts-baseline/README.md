# Deforestation Alerts Baseline Analysis

> See [brief.md](./brief.md) for context, signals, and findings, and
> [pipeline.md](./pipeline.md) for a technical walkthrough.

In this experiment, we generate a baseline of alerts data for the target
AOI, and then provide the baseline as well as recent alerts data to an
LLM for summarization. These are generated using the WRI Global Forests
Watch data API for deforestation alerts, and statistical summaries,
generated in python.

The LLM is also given basic information about the AOI itself, and a
persona of the target audience.

## Background: Places to Watch collaboration

This experiment was developed in collaboration with WRI's
[Places to Watch](https://gfw.global/KWZV0t) (PTW) program, which identifies
protected areas at elevated deforestation risk.

In initial discussion with the PTW team, we proposed and revised the
experiment concept, identified a target site, and understand the target
audience.

Tesso Nilo National Park (Riau, Indonesia) was selected as the
test case, and July 2023 as a target month for the summary. Tesso
Nilo is a high-profile PTW site with documented encroachment pressure
and there are existing reports generated by PTW and their partners
for the month of July 2023.

Follow-up discussion surfaced open questions about improving the seasonal
baseline and better defining the target persona.

A shared collaboration document was used to capture discussion notes, define
user personas, and develop the `USER_NEEDS` prompt variable.

## Running the notebooks

Setup and usage to run the notebooks.

Prerequisites
- Python 3.13+
- `uv` must be installed
- A WRI Data API key (contact the GFW team)

Environment variables
- Set `WRI_DATA_API_KEY` before running the notebooks.
    - optional use mise or .env files to manage environment variables

Run the notebooks
- Both notebooks are self-contained marimo scripts with inline dependencies.
- Run from the `src/` directory:

```bash
# API exploration and data validation
cd src/
uv run marimo edit --sandbox explore_api.py

# Baseline computation and trend analysis
uv run marimo edit --sandbox baseline_analysis.py
```
